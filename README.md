# VexCommerce Storefront Reference

`[VXG RealForever]`

This repository is the **public synthetic reference storefront owner** for the reusable VexWork Commerce starter.

Its purpose is deliberately narrow:

- own one tiny public static storefront surface;
- prove that an AI-assisted workflow can create and later revise public item content;
- keep VexWork as the work/navigation console rather than the storefront database;
- use synthetic/public-safe fixtures only;
- never store customer identity, shipping addresses, payment credentials, provider secrets, or real order data.

The first fixture is intentionally not the Antique Plate lived business pilot. P5 may consume this pattern while selecting or forming its own rightful site/storefront owner.

## Source

- `storefront.json` — current synthetic storefront content.
- `index.html` — static same-origin reader.
- `.nojekyll` — keeps publication static and generator-free.

## Authority boundary

Preparing or changing these files is repository source work.

Publication evidence is separate from VexWork WorkState, and this repository does not own VexWork lifecycle truth.
